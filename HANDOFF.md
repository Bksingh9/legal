## Roadmap — execute in order, do not skip ahead

Spec §9 is immutable for the first 90 days. Today the scaffold (W1–2) is done. Your work starts at W3–4.

### Week 3–4: Tier 1 AI triage
- Email-gated chat at `/triage`. Magic-link auth via Supabase. Phone OTP optional in v1.
- `POST /api/triage/classify` — Haiku returns `{classification, urgency, confidence}`.
- `POST /api/triage/prep` — Sonnet returns the 1-page Case Prep with: plain-language summary, likely sections (cite acts/sections only, never cases), next 3 steps, documents to gather, urgency. Use `messages.stream` for incremental render.
- Generate the Case Prep PDF server-side (use `@react-pdf/renderer` or a simple HTML-to-PDF via Puppeteer on Vercel functions — pick the lighter option). Store in Supabase Storage. Persist row in `queries`.
- Bilingual (Hindi + English) input. Detect via Claude. Output in user's input language.
- Voice input: browser MediaRecorder → POST audio to `/api/triage/transcribe` → Anthropic transcription or Sarvam.ai for Hindi → feed into classify+prep pipeline.
- Soft CTAs at end of Case Prep: "Generate the legal document" → /documents/{type}, "Get a 15-min lawyer call" → /consult.
- Disclaimer banner on every triage response.

### Week 5–6: Tier 2 document automation + Razorpay
- Five SKUs to ship first: legal notice (₹499), reply to legal notice (₹699), rent agreement 11-month (₹399), consumer complaint NCDRC (₹599), RTI application (₹199). Cheque bounce S.138 (₹699) and NDA (₹599) follow.
- Per-SKU guided form (zod schemas) → Claude fills a deterministic template (no free-form drafting; templates live in `lib/templates/<sku>.ts`).
- Preview screen → Razorpay checkout → on `payment.captured` webhook (signature-verified) generate final PDF + DOCX, store in Storage, email via Resend, WhatsApp via AiSensy.
- "Lawyer review" add-on (+₹499): writes a `lawyer_reviews` row, surfaces in lawyer queue (W7–8).
- Idempotency on `payments.idempotency_key`. Razorpay webhook is the source of truth, not the client.

### Week 7–8: Lawyer onboarding + KYC
- `/lawyer/apply` — Bar Council ID, state, specializations, languages, years, payout account (UPI VPA + IFSC).
- KYC: DigiLocker hook for advocate ID where available; else manual admin verification queue.
- Anonymized internal lawyer card (id, specialization, years, anonymized rating). **Never expose lawyer name to other users.**
- Razorpay Route account creation per lawyer.
- Admin `/admin/lawyers` page (founder-only, role check) to verify/suspend.

### Week 9–10: Tier 3 consultation flow
- Pricing packs: 15min ₹199, 30min ₹349, 60min ₹599. Razorpay holds funds.
- Match algorithm: filter active lawyers by specialization + language + state, sort by load + rating, notify top 3 via WhatsApp + push, first to accept wins. Target match-time <4h.
- Exotel masked-number callback OR 100ms video room. User picks.
- Auto-transcribe via Claude (Sonnet) post-call → email summary via Resend → save to `consultations.summary` and `transcript_url`.
- Both-party recording consent prompt at call start. If either declines, record nothing.
- Lawyer payout: 55–65% of net (after platform fee + GST). Hold funds 24h, then release via Razorpay Route.
- Dispute path: "Not satisfied" → free re-match or 50% wallet credit.

### Week 11–12: Subscriptions + referral + SEO + bug bash
- LegalDesk Plus ₹999/year via Razorpay Subscriptions. Entitlements: unlimited docs, 60 mins consultation/year, priority callback (<1h), document vault + renewal reminders.
- Referral: `wallet` ledger entries — ₹100 on signup, ₹250 on first paid txn. Unique referral codes per user.
- 50 SEO articles in `/blog`. Generate with Claude (Sonnet) from a list of intent keywords I'll provide. Founder reviews before publish. Never name a lawyer. Each article has structured data (FAQPage/Article schema).
- Bug bash: hit every flow, write Playwright smoke tests for the golden paths (triage → doc → pay; signup → consult).
